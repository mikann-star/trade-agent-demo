# 交易 Agent

一个用于产品演示的中文多智能体交易业务工作台。交易主理人会根据问题调度日常运营、商品运营、招商、营销活动和项目管理五个专家 Agent，并在界面中实时展示工具调用和生成结果。

## 能力

- 浏览器内模拟 manager-style 多 Agent 调度
- 确定性的流式回答与执行事件
- 内置确定性交易业务演示数据
- KPI 表格、诊断报告、项目计划和 CSV 导出
- 黑白线框三栏工作台与移动端抽屉
- GitHub Pages 静态部署，无需登录或后端服务

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。演示不需要 API 密钥，刷新页面后会清空当前对话。

## 异步回复与版本记录

发送问题后，回复卡片从「预览版1」开始。回复卡片右上方的「查询任务进度」会保存新的预览快照，查询期间按钮置灰。
分析完成后，原卡片自动切换为最终结果，无需再次查询。通过左上角版本选择器可查看每个版本，入口直接显示当前选中的「最终版」或「预览版X」。预览版2及之后显示「本次点击查询的时间 ～ 该次查询结果输出时间」；预览版1与最终版以原任务提交时间为起点，所有时间精确到秒。回复底部不再重复展示时间和耗时。
「查询任务进度」仅保留在回复卡片右上方，查询对应轮次。最终版生成后按钮置灰，切换到历史预览时也不会重新启用；版本选择器仍可使用。

本地演示的分析阶段约 16 秒，查询延迟约 1.8 秒，便于体验多次查询及最终结果先于查询响应返回的情况。
晚到的查询响应仍保存为预览版，默认显示始终优先最终版。重新生成会保留旧回复并新增回复卡片。
本项目没有后端；进度查询适配器位于 `lib/answer-versions.ts`，完成推送由原有异步模拟事件驱动。接入真实服务时替换查询适配器与完成事件来源即可。

## 网站与一键部署

在线访问：https://mikann-star.github.io/trade-agent-demo/

推送到 `main` 分支后，GitHub Actions 会自动测试、构建并发布当前版本。
也可以进入仓库 **Actions → Deploy frontend demo to GitHub Pages → Run workflow**，选择 `main` 后一键重新部署。

部署仅使用当前分支，不依赖旧版本分支。页面不展示缺失历史版本的切换入口。
仓库 **Settings → Pages → Build and deployment → Source** 应设为 **GitHub Actions**。

所有业务数据均为虚构演示数据，应用不会连接、读取或修改真实业务系统。
